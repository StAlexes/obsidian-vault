| Экземпляры |

Механизм экземпляров обеспечивает возможность вести параллельную копию структуры справочника со сложной иерархией в виде объектов справочника простой иерархии, в котором каждый из объектов связан с объектом исходного справочника и имеет независимый набор параметров и связей

![Изображение](../icons/SectionExpanded.png)Пример работы с экземплярами

C#

[Копировать](# "Копировать")

```
using TFlex.DOCs.Model.Macros;

public class Macro(MacroContext context) : MacroProvider(context)
{
    public override void Run()
    {
        var objectInstance = Context.ReferenceObjectInstance; // Получаем текущий экземпляр
        var sourceObject = objectInstance?.ReferenceObject; // Получаем соответствующий объект исходного справочника
        var hierarchyLink = objectInstance?.ComplexHierarchyLink; // Получаем связанное подключение исходного справочника
    }
}
```
