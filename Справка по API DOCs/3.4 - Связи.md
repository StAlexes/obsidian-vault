![Изображение](../icons/SectionExpanded.png)Команды для работы со связями.

[Объект.СвязанныйОбъект](76D34911.htm)
[["(имя связи 1:1 или N:1)"]](619B56AA.htm)
- возвращает связанный объект.

C#

[Копировать](# "Копировать")

```
Объект файл = ТекущийОбъект.СвязанныйОбъект["Файл"];
string наименованиеФайла = файл == null ? "Нет связанного файла" : файл.Параметр["Наименование"];
```

[Объект.СвязанныйОбъект](76D34911.htm)
[["(имя связи 1:1 или N:1)"] = (объект)](619B56AA.htm)
- устанавливает связанный объект

C#

[Копировать](# "Копировать")

```
Объект файл = НайтиОбъект("Файлы", "Наименование", "Мой документ.pdf");
ТекущийОбъект.СвязанныйОбъект["Файл"] = файл; // Подключает объект по связи
ТекущийОбъект.СвязанныйОбъект["Документ"] = null; // Отключает объект по связи
```

[Объект.СвязанныеОбъекты](63B6CCBA.htm)
[["(имя или Guid связи 1:N или N:N, или на любой справочник)"]](619B56AA.htm)
- возвращает список связанных объектов.

C#

[Копировать](# "Копировать")

```
Объекты документы = ТекущийОбъект.СвязанныеОбъекты["Документы"];

foreach (Объект документ in документы)
{
    ТекущийОбъект.Отключить("Документы", документ);
}
```

[Объект.Подключить("Наименование связи", (объект))](3B43D424.htm)
- подключает объект по связи.

C#

[Копировать](# "Копировать")

```
Объект файл = НайтиОбъект("Файлы", "Наименование", "Мой документ.pdf");

if (файл is not null)
    ТекущийОбъект.Подключить("Файлы", файл);
```

[Объект.Отключить("Наименование связи")](B89BC1FC.htm)
- отключает объект по связи 1:1, N:1
[Объект.Отключить("Наименование связи", (объект))](5A19FA12.htm)
- отключает объект по связи 1:N, N:N, или на любой справочник

C#

[Копировать](# "Копировать")

```
Объекты файлы = ТекущийОбъект.СвязанныеОбъекты["Файлы"];

foreach (Объект файл in файлы)
{
    if (файл.Параметр["Наименование"] == "Мой документ.pdf")
    {
         ТекущийОбъект.Отключить("Файлы ", файл);
         break;
    }
}
```
