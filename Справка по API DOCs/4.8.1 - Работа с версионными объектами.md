| Работа с версионными объектами |

![Изображение](../icons/SectionExpanded.png)Работа с версионными объектами (для справочников с поддержкой истории)

Некоторые справочники поддерживают версионные объекты. Работа с такими объектами производится следующим образом:

Проверка поддержки истории изменения:

C#

[Копировать](# "Копировать")

```
referenceObject.Reference.ParameterGroup.SupportsDesktop;
```

Перед тем как перевести объект в состояние редактирования, его необходимо взять на редактирование:

C#

[Копировать](# "Копировать")

```
referenceObject.CheckOut(false); // Берем объект на редактирование
referenceObject.BeginChanges();
```

Для редактирования объекта с сохранением текущих подписей в неактуальном состоянии необходимо воспользоваться одной из перегрузок метода
[Desktop.CheckOut()](69E4CD79.htm)
, т.к. в противном случае, при отсутствии доступа на изменение объекта с сохранением подписей, подписи будут удалены

C#

[Копировать](# "Копировать")

```
TFlex.DOCs.Model.Desktop.Desktop.CheckOut(referenceObject, false, null, true); // Берем объект на редактирование с сохранением подписей в неактуальном состоянии
referenceObject.BeginChanges();
```

Проверка возможности взятия объекта на редактирование:

C#

[Копировать](# "Копировать")

```
if (referenceObject.CanCheckOut)
    referenceObject.CheckOut(false);
```

Проверка того факта, что объект взят на редактирование:

C#

[Копировать](# "Копировать")

```
if (referenceObject.IsCheckedOut)
{
}
```

Проверка того факта, что объект взят на редактирование текущим пользователем:

C#

[Копировать](# "Копировать")

```
if (referenceObject.IsCheckedOutByCurrentUser)
{
}
```

Отличить только что созданный объект от объекта взятого на редактирование можно с помощью свойства LockState:

C#

[Копировать](# "Копировать")

```
if (referenceObject.LockState == ReferenceObjectLockState.CheckedOutForAdd) // Создан на рабочем столе
{
}
else if (referenceObject.LockState == ReferenceObjectLockState.CheckedOutForEdit) // Взят на редактирование
{
}
```

Ссылки:

[TFlex.DOCs.Model.ReferencesReference](26AE86E6.htm)

После редактирования объекта необходимо применить изменения:

C#

[Копировать](# "Копировать")

```
// Действия над объектом
referenceObject.EndChanges(); // Фиксируем изменения
referenceObject.CheckIn("Применяем изменения"); // Применяем изменения
```

Отмена изменений:

C#

[Копировать](# "Копировать")

```
if (referenceObject.Changing)
    referenceObject.CancelChanges();

referenceObject.UndoCheckOut();
```

Удаление объекта:

C#

[Копировать](# "Копировать")

```
referenceObject.CheckOut(true);
referenceObject.CheckIn("Удаление объекта");

// Если справочник поддерживает корзину, можем удалить объект из нее
if (referenceObject.Reference.ParameterGroup.SupportsRecycleBin)
    TFlex.DOCs.Model.Desktop.Desktop.ClearRecycleBin(referenceObject);
```

Если необходимо произвести операции над коллекцией объектов, то можно воспользоваться классом Desktop:

C#

[Копировать](# "Копировать")

```
ReferenceObject[] referenceObjects;
// Применяем изменения без отображения диалога "Применение изменений"
TFlex.DOCs.Model.Desktop.Desktop.CheckIn(referenceObjects, "Применение изменений", false);
```
