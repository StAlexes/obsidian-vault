| Объекты списка |

Список объектов является аналогом связи внутри объекта. Изменение параметров и связей объекта списка аналогично объекту справочника (см. [«Редактирование объектов»](663e0b41-ed90-4985-bdca-da4741702f3e.htm#EditObjectSection)).

При работе с объектами списка необходимо учитывать следующую информацию:

- Объект списка создается от владельца (при помощи метода
  [ReferenceObject.CreateListObject()](32603F7F.htm)
  , см. пример), а не от справочника
- Идентификатор (Id) созданного объекта списка равен нулю до сохранения владельца
- Объект списка можно создавать и редактировать только если владелец взят на редактирование
- Применить изменения к объекту списка нужно до сохранения владельца
- Для получения объекта справочника, которому принадлежит объект списка, т.е. владельца, необходимо обратиться к свойству
  [ReferenceObject.MasterObject](ADE22359.htm)
  объекта списка

![Изображение](../icons/SectionExpanded.png)Алгоритм внесения изменений в объект списка

- Создание или перевод в состояние редактирования объекта справочника (владельца). Созданный объект не нужно брать на редактирование

  - Создание или перевод в состояние редактирования объекта списка. Созданный объект не нужно брать на редактирование
  - Редактирование объекта списка (изменение параметров, связей и т.д.)
  - Фиксирование окончания изменений или отмена изменений для объекта списка
- Фиксирование окончания изменений или отмена изменений для объекта справочника

![Изображение](../icons/SectionExpanded.png)Пример создания и редактирования объектов списка

C#

[Копировать](# "Копировать")

```
using System;
using System.Collections.Generic;
using TFlex.DOCs.Model.Macros;
using TFlex.DOCs.Model.References;
using System.Linq;

public class Macro : MacroProvider
{
    public Macro(MacroContext context)
        : base(context)
    { }

    public override void Run()
    {
        // В коде необходимо пустые значения глобальных идентификаторов (Guid.Empty) заменить на реальные

        var referenceObject = Context.ReferenceObject;

        if (!referenceObject.CanEdit) // Проверяем возможность редактирования текущего объекта
            return;

        var editableListObjects = new List<ReferenceObject>(2); // Коллекция для хранения редактируемых объектов списка
        try
        {
            if (!referenceObject.Changing)
                referenceObject.BeginChanges(); // Переводим в состояние редактирования объект справочника

            var listObjects = referenceObject.GetObjects(Guid.Empty); // Получаем объекты списка
            var listObject1 = listObjects.FirstOrDefault(); // Берем первый

            if (listObject1 is not null)
            {
                listObject1.BeginChanges(false); // Переводим в состояние редактирования объект списка. Т.к. объект списка только что получен по связи, то передаем в метод false, тем самым не перезагружаем объект
                listObject1[Guid.Empty].Value = 1; // Устанавливаем значение параметра
                editableListObjects.Add(listObject1);
            }

            // Удаляем объект списка
            if (listObjects.Count > 1)
            {
                var deletedListObject = listObjects.Last();
                deletedListObject.Delete();
            }

            // Создаем объект списка. Брать на редактирование не нужно! Созданный объект уже в состоянии редактирования
            var newistObject = referenceObject.CreateListObject(Guid.Empty, Guid.Empty);
            newistObject[Guid.Empty].Value = 1;
            editableListObjects.Add(newistObject);

            foreach (var listObject in editableListObjects)
                listObject.EndChanges(); // Фиксируем изменения для всех редактируемых объектов списка

            referenceObject.EndChanges(); // Фиксируем изменения для объекта справочника
        }
        catch
        {
            foreach (var listObject in editableListObjects.Where(lo => lo.Changing)) // Отменяем изменения для редактируемых объектов списка
                listObject.CancelChanges();

            // Отменяем изменения для редактируемого объекта справочника
            if (referenceObject.Changing)
                referenceObject.CancelChanges();

            throw;
        }
    }
}
```
