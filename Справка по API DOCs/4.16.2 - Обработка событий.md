| Обработка событий |

Если действие в системе направлено на объект или подключение в целом, то для обработки события достаточно информации о текущем объекте или подключении, которую можно получить из контекста выполнения макроса
[MacroContext](FBAE736E.htm):

C#

[Копировать](# "Копировать")

```
ReferenceObject currentObject = Context.ReferenceObject; // Получаем текущий объект
ComplexHierarchyLink hierarchyLink = Context.HierarchyLink; // Получаем текущее подключение
```

К таким события относятся: «Удаление объекта», «Создание объекта», «Сохранение объекта», «Завершение сохранения объекта», «Создание подключения», «Удаление подключения».

Для ряда событий контекст выполнения макроса предоставляет возможность получения аргументов событий через свойство
[ModelChangedArgs](162B83B8.htm).

Аргументы событий позволяют получить данные, связанные с инициированными событиями.

C#

[Копировать](# "Копировать")

```
ModelEventArgs modelEventArgs = Context.ModelChangedArgs; // Получаем аргументы события изменения в модели
```

Класс ModelEventArgs является базовым типом для всех классов аргументов событий.
В зависимости от обрабатываемого события необходимо привести свойство [ModelChangedArgs](162B83B8.htm) к нужному типу для получения аргументов.
Типы и аргументы, соответствующие конкретному событию, описаны далее

Для этого необходимо вызвать команду макроязыка [Отменить()](497C970C.htm) или сгенерировать соответствующее исключение: [throw new MacroException(true)](695F657A.htm).    Пример с отменой действия: [«Изменение связи объекта»](2D30B162-AE9D-4B91-8D30-29004B83000E.htm) |

[ObjectParameterChangingEventArgs](6D6CA146.htm)
- аргументы события изменения параметра объекта справочника

[ObjectParameterChangedEventArgs](44D033B1.htm)
- аргументы события завершения изменения параметра объекта справочника

ObjectParameterChangedEventArgs и ObjectParameterChangingEventArgs предоставляют информацию об изменяемом параметре через свойство [Parameter](F524E329.htm),
а также позволяют узнать предыдущее значение параметра через свойство [OldValue](DADFB057.htm)
и новое значение через свойство [NewValue](446AA71.htm)

Пример работы с данными аргументами событий: [«Завершение изменения параметра объекта»](72c6f9f1-cbc7-47aa-ae76-a2baa20107c8.htm)

![Изображение](../icons/SectionExpanded.png)Аргументы событий «Изменение связи объекта» и «Завершение изменения связи объекта»

[ObjectLinkChangingEventArgs](BF1F5E29.htm)
- аргументы события изменения связи объекта справочника

[ObjectLinkChangedEventArgs](80309CC9.htm)
- аргументы события завершения изменения связи объекта справочника

ObjectLinkChangedEventArgs и ObjectLinkChangingEventArgs предоставляют информацию об изменяемой связи через свойство [Link](9E0B55C1.htm),
а также позволяют узнать какой объект был подключен через свойство [AddedObject](E7B2C775.htm)
или отключен - RemovedObject

Пример работы с данными аргументами событий: [«Изменение связи объекта»](2D30B162-AE9D-4B91-8D30-29004B83000E.htm)

- аргументы события изменения стадии объекта справочника

[ObjectStageChangedEventArgs](E4FD453.htm)

и о новой стадиии через свойство [NewStage](9C7482B5.htm)

- аргументы события изменения порядкового номера объекта справочника

ObjectOrderChangedEventArgs позволяет получить информацию о старом значении номера через свойство [OldOrder](EEB183D3.htm)
и о новом значении номера через свойство [NewOrder](C15B39EB.htm)

- аргументы события применения изменений объекта справочника

[ObjectDesktopCheckInEventArgs](DAA53C80.htm)
- аргументы события завершения применения изменений объекта справочника

ObjectDesktopCheckingInEventArgs и ObjectDesktopCheckInEventArgs позволяют получить описание операции рабочего стола через свойство [Operation](1B94BAA2.htm).
Описание операции рабочего стола содержит тип операции ([Type](C1AD10E8.htm));
список объектов, для которых выполняется операция ([Items](E30BEE19.htm));
комментарий ([Comment](E715E786.htm));
флаг, отвечающий за необходимость оставить объект в работе ([KeepCheckedOut](A0A81436.htm))

Пример работы с данными аргументами событий: [«Операции с рабочим столом»](B7EDC662-324B-4243-9E58-C73A88A34BF3.htm)
