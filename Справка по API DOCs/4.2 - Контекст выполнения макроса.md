| Контекст выполнения макроса |

Контекст выполнения макроса ([MacroContext](FBAE736E.htm)) представляет собой набор свойств, определяющих окружение,
в котором выполняется макрос, а также методов, позволяющих взаимодействовать с данным окружением

![Изображение](../icons/SectionExpanded.png)Свойства и методы контекста выполнения макроса

[Connection](B62CE463.htm)
- возвращает текущее [соединение с сервером](EAA7893.htm).
Подробнее о соединении с сервером: [«Соединение с сервером приложений»](590BF971-0256-450B-8D9D-46C870673B97.htm)

[Reference](D3D8EBB6.htm)
- возвращает текущий справочник

[ConfigurationSettings](5C677535.htm)
- возвращает настройки конфигурации текущего справочника

C#

[Копировать](# "Копировать")

```
var currentConfigurationSettings = Context.ConfigurationSettings; // Получаем настройки конфигурации текущего справочника

var newConfigurationSettings = new ConfigurationSettings(currentConfigurationSettings)
{
    Date = "Сегодня",
    ApplyDate = true
}; // Создаем новые настройки на основе текущих
```

[ReferenceObject](1EB2754D.htm)
- возвращает текущий объект

[HierarchyLink](106EBF25.htm)
- возвращает текущее подключение

C#

[Копировать](# "Копировать")

```
ReferenceObject currentObject = Context.ReferenceObject; // Получаем текущий объект
ComplexHierarchyLink hierarchyLink = Context.HierarchyLink; // Получаем текущее подключение
```

[ModelChangedArgs](162B83B8.htm)
- возвращает аргументы события изменения в модели.
Подробнее об аргументах событий: [«Обработка событий»](4D29D69A-34E1-44D8-A992-B86804402A95.htm)

[IsAdministrator](90177E13.htm)
- возвращает значение, указывающее, является ли текущий пользователь администратором системы

[CancellingChanges](115A2EBC.htm)
- возвращает значение, указывающее, выполняется ли отмена изменений при завершении редактирования свойств текущего объекта.
Подробнее отмене изменений: [«Завершение редактирования свойств объекта»](2615B67A-434D-4CBC-B45F-1D35779C4505.htm)

[ShowMessage(caption, text[, args])](C1F25E9D.htm)
- показывает сообщение

C#

[Копировать](# "Копировать")

```
Context.ShowMessage("Результат", "Объекты успешно сохранены");
```

[ShowQuestion(text)](6EA0C83F.htm)
- показывает сообщение с иконкой "Вопрос" и вариантами Да/Нет

C#

[Копировать](# "Копировать")

```
if (Context.ShowQuestion("Внимание", "Объекты будут удалены, продолжить?"))
{
    // ...
}
```

[RunOnUIThread(action)](A8543C12.htm)
- выполняет указанный метод в UI-потоке. Макросы выполняются в рабочем потоке, поэтому взаимодействие с UI необходимо передать в данный метод.
Подробнее о выполнении в UI-потоке: [«Программное открытие вкладок»](2D145ADD-A87F-4DCE-8789-3DE04DC03412.htm)

[ShowClassObjectSelectionDialog(referenceName[, caption])](7193B2A6.htm)
- отображает диалог выбора типа объекта справочника

C#

[Копировать](# "Копировать")

```
// Показываем диалог выбора типа
TFlex.DOCs.Model.Classes.ClassObject classObject = Context.ShowClassObjectSelectionDialog("Группы и пользователи", "Выбор типа");

if (classObject is not null)
{
    // ...
}
```

[CloseDialog(saveChanges[, showConfirmationOnCancel])](88BB8D5D.htm)
- закрывает диалог свойств объекта с возможностями сохранения изменений и отображения подтверждения при отмене
