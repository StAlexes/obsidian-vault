| PdmFramework |

Библиотека входит в стандартную поставку клиента T-FLEX DOCs.
PdmFramework представляет собой набор интерфейсов (контрактов) и их реализаций для интеграции с PDM-системой T-FLEX DOCs, что позволяет взаимодействовать с различными модулями и сервисами T-FLEX DOCs из внешних приложений.
Взаимодействие внешних приложений с T-FLEX DOCs через данную библиотеку не является обязательным. PdmFramework - часть API T-FLEX DOCs, представляющая собой удобную абстракцию.

![Изображение](../icons/SectionExpanded.png)Основные интерфейсы

- [IServiceSet](6CBBA3BE.htm)
  - набор сервисов, предоставляемых PDM-системой. Обеспечивает подключение к DOCs, доступ к различным справочникам (файлы, ЭСИ, документы, материалы), работу с рабочим столом, поиском, корзиной, замечаниями и почтой
- [IDesktop](2823B5E8.htm)
  - интеграция с рабочим столом DOCs. Позволяет создавать элементы управления рабочего стола, выполнять операции с файлами (check-in, check-out, undo check-out)
- [INomenclatureControl](41FF1604.htm)
  - элемент управления справочника ЭСИ. Предоставляет методы для навигации и управления структурой изделия
- [INomenclatureReference](CAA629A8.htm)
  - интеграция со справочником ЭСИ. Позволяет создавать и искать объекты ЭСИ, сохранять структуру сборок, генерировать обозначения по классификатору и т.д.
- [IMaterial](E70634A.htm)
  - интерфейс для работы с материалами. Предоставляет доступ к свойствам материала
- [IRecycleBin](5CCAF587.htm)
  - интеграция с корзиной DOCs. Позволяет создавать элементы управления корзиной
- [ISearch](E617E7A5.htm)
  - интеграция с поиском DOCs. Предоставляет методы для создания элементов управления поиском
- [ICertificate](A19F5064.htm)
  - описание PDM-системы (название, версия, данные о подключении)

Другие важные интерфейсы: [IFileRepository](7D5000FE.htm) - справочник "Файлы";
[IConfigurationSettingsGateway](6CEA2E1.htm) - окно конфигурации;
[IRemarksReference](9C3970C.htm) - работа с замечаниями;
[IMail](195499F0.htm) -интеграция с почтой.
Для использования сервисов необходимо получить экземпляр [IServiceSet](6CBBA3BE.htm) через вызов метода [Connect()](22FB0405.htm).
После завершения работы следует вызвать метод [Disconnect](2B8F67BC.htm).
Набор контрактов предоставляет широкие возможности для интеграции с T-FLEX DOCs, позволяя создавать плагины и расширения, автоматизировать работу с PDM-системой и реализовывать пользовательские интерфейсы для управления данными.
