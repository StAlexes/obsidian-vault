| Электронная структура изделий (ЭСИ) |

| Внимание  Внимание |
| --- |
| Данный раздел предназначен для описания работы с устаревшим механизмом, основанном на взаимодействии справочника ЭСИ со связанными справочниками (Документы, Материалы, Электронные компоненты и т.д.).  На текущий момент работа с объектами справочника ЭСИ не отличается от работы с другими справочниками системы. Подробнее о работе с объектами: [«Создание, редактирование объектов»](458f2560-c2d9-4615-ae01-fe575141692d.htm#EditObjectSection) |

![Изображение](../icons/SectionExpanded.png)Команды для работы с ЭСИ

[ЭСИ.Подключить((объект)[, (родительский объект)])](1F7A39CD.htm)
- подключает объект к ЭСИ

C#

[Копировать](# "Копировать")

```
Объект объектЭси = ЭСИ.Подключить(ТекущийОбъект);
```

[Объект.СвязанныйОбъект](76D34911.htm)
[["Связанный объект"]](619B56AA.htm)
- возвращает связанный объект для объекта ЭСИ

C#

[Копировать](# "Копировать")

```
Объект связанныйОбъект = объектЭси.СвязанныйОбъект["Связанный объект"];
```

[Объект.СвязанныйОбъект](76D34911.htm)
[["Объект ЭСИ"]](619B56AA.htm)
- возвращает объект ЭСИ, связанный с данным объектом

C#

[Копировать](# "Копировать")

```
Объект объектЭси = ТекущийОбъект.СвязанныйОбъект["Объект ЭСИ"];
```
