Команды для запуска бизнес-процессов

[БизнесПроцессы.Запустить(наименование[, переменные, показывать диалог, шаблон переменных, начало, вспомогательныеОбъекты])](4F5CA25D.htm)
- запускает бизнес-процесс по наименованию

[БизнесПроцессы.Запустить(наименование, объект[, переменные, показывать диалог, шаблон переменных, начало, вспомогательныеОбъекты])](D5BBD7E2.htm)
- запускает бизнес-процесс по наименованию с возможностью подключения объекта

[БизнесПроцессы.Запустить(наименование, объекты[, переменные, показывать диалог, шаблон переменных, начало, вспомогательныеОбъекты])](338CD7E2.htm)
- запускает бизнес-процесс по наименованию с возможностью подключения объектов

Пример запуска бизнес-процессаC#[Копировать](# "Копировать")

```
Объекты объектыПоБП = НайтиОбъекты("Документы", "[Тип] = 'Изделие'"); // Находим объекты, которые подключим к БП

var переменные = new Dictionary<string, object>  // Список из пар "Наименование переменной" + "значение"
{
    {"Переменная1", 5},
    {"Переменная2", "текстовое значение"}
};

// Запускаем бизнес-процесс
БизнесПроцессы.Запустить(
    "Тестовый бизнес-процесс", // Наименование бизнес-процесса
    объектыПоБП, // Идущие по процессу объекты
    переменные, // Список наименований и значений переменных
    false); // Скрываем мастер запуска
```

[БизнесПроцессы.ЗапуститьЛинейныйПроцесс(Прототип, объекты[, показывать диалог])](3A1DDA1C.htm)
- запускает линейный бизнес-процесс по прототипу с возможностью подключения объектов

Пример запуска линейного бизнес-процессаC#[Копировать](# "Копировать")

```
Объект документ = НайтиОбъект("Документы", "[ID] = '1'"); // Находим объект, который подключим к линейному БП

// Запускаем линейный бизнес-процесс по прототипу с отображением диалога
БизнесПроцессы.ЗапуститьЛинейныйПроцесс("Прототип", документ, true);
```
