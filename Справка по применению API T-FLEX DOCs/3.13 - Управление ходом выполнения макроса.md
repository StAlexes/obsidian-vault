Команды для управления ходом выполнения макроса

[`ВыполнитьМакрос(макрос[, метод, параметры])`]
- запускает на выполнение указанный макрос, с возможностью указать наименование выполняемого метода и передать ему список аргументов.
Если макрос возвращает значение, команда вернёт значение

C#

```csharp
var значение = ВыполнитьМакрос("Вычислить значение");
ВыполнитьМакрос("63978998-81b0-4e53-95b0-472c69f23fb0", "НазначитьНомер");
```csharp
`ИнициироватьСобытие(событие)`
- инициирует пользовательское событие с заданным именем.

C#

```csharp
ИнициироватьСобытие("Назначить номер");
```csharp
`Прервать()`
- прерывает выполнение макроса.

C#

```csharp
if (ТекущийОбъект.Параметр["Количество"] == 0)
    Прервать();
```csharp
`Отменить()`
- отменяет применение/отмену изменений, удаление объекта, создание/удаление подключений сложной иерархии с выводом сообщения "Действие отменено макросом"
`Отменить(показывать сообщение)`
- отменяет применение/отмену изменений, удаление объекта, создание/удаление подключений сложной иерархии с возможностью скрыть сообщение о прерывании выполнения макроса
[`Отменить(сообщение[, параметры])`]
- отменяет применение/отмену изменений, удаление объекта, создание/удаление подключений сложной иерархии с выводом форматированного сообщения об ошибке (см.
[System.String.Format](https://learn.microsoft.com/dotnet/api/system.string.format) )

C#

```csharp
if (ТекущийОбъект.Параметр["Количество"] == 0)
    Отменить();
else if (ТекущийОбъект.Параметр["Количество"] < 0)
    Отменить("Кол-во = {0} меньше нуля", ТекущийОбъект.Параметр["Количество"]);
```csharp
