Команды для работы с подключениями в справочниках со сложной иерархией

[ТекущееПодключение](C319DCF8.htm)
- возвращает подключение текущего объекта к родительскому

[СоздатьПодключение((родительскийОбъект), (дочернийОбъект))](93CD245E.htm)
- создает подключение дочернего объекта к родительскому

C#[Копировать](# "Копировать")

```
Подключение подключение = СоздатьПодключение(родительскийОбъект, дочернийОбъект);
```

[Подключение.Удалить()](BA5AB278.htm)
- удаляет подключение

[Подключение.Изменить()](CDE5C582.htm)
- переводит подключение в состояние редактирования

[Подключение.Сохранить()](86044BDE.htm)
- сохранение изменений

[Подключение.ОтменитьИзменения()](859022B5.htm)
- отмена изменений

| Внимание |
| --- |
| Каждому вызову команды Изменить() должен соответствовать вызов команды Сохранить() или ОтменитьИзменения() |

[Подключение](F8466936.htm)
[["(Параметр подключения)"]](D54880B2.htm)
- доступ к параметру подключения

C#[Копировать](# "Копировать")

```
подключение["Количество на изделие"] = 5;
```

[Подключение.Параметр](46A0D830.htm)
[["(Параметр подключения)"]](618A4278.htm)
- доступ к параметру подключения

C#[Копировать](# "Копировать")

```
подключение.Параметр["Входит в спецификацию"] = false;
```

[Подключение.Редактируется](A79D1491.htm)
- показывает, находится ли подключение в состоянии редактирования

C#[Копировать](# "Копировать")

```
if (!подключение.Редактируется)
    подключение.Изменить();
```

[Подключение.РодительскийОбъект](8149BE39.htm)
- возвращает родительский объект подключения

C#[Копировать](# "Копировать")

```
Объект объект = подключение.РодительскийОбъект;
```

[Подключение.ДочернийОбъект](DAFE62E6.htm)
- возвращает дочерний объект подключения

C#[Копировать](# "Копировать")

```
Объект объект = подключение.ДочернийОбъект;
```

[Объект.ДочерниеПодключения](B9931961.htm)
- возвращает список дочерних подключений объекта

C#[Копировать](# "Копировать")

```
foreach (var дочернееПодключение in ТекущийОбъект.ДочерниеПодключения)
{
    дочернееПодключение.Удалить();
}
```

[Объект.РодительскиеПодключения](F56C8FCA.htm)
- возвращает список родительских подключений объекта

C#[Копировать](# "Копировать")

```
foreach (var родительскоеПодключение in ТекущийОбъект.РодительскиеПодключения)
{
    родительскоеПодключение.Изменить();
    родительскоеПодключение["Количество на изделие"] = 5;
    родительскоеПодключение.Сохранить();
}
```

[Объект.СвязанноеПодключение](2A7C2C78.htm)
- возвращает связанное подключение

C#[Копировать](# "Копировать")

```
Подключение подключение = ТекущийОбъект.СвязанноеПодключение["Наименование связи"];
```

[Объект.СвязанныеПодключения](2A77A1AF.htm)
- возвращает связанные подключения

C#[Копировать](# "Копировать")

```
Подключения подключения = ТекущийОбъект.СвязанныеПодключения["Наименование связи"];
```

[Объект](7A1D77DE.htm)
[["(путь к параметру подключения)"]](525905A3.htm)
- возвращает доступ к параметру подключения (доступ к параметрам подключения есть только у объектов, полученных через свойство ДочерниеОбъекты родительского объекта).

C#[Копировать](# "Копировать")

```
Объект деталь = Изделие.ДочерниеОбъекты.First();
int count = деталь["[Подключения].[Количество]"];
```
