Команды для работы с подписями.

[Объект.Подписи](280719D7.htm)
- Возвращает список подписей объекта.

C#[Копировать](# "Копировать")

```
foreach (Подпись подписьОбъекта in ТекущийОбъект.Подписи)
{
    // ...
}
```

[Объект.ДобавитьПодпись("(Тип подписи)", (пользователь))](8C38D60.htm)
- Добавляет подпись к объекту. Возвращает True, если подпись успешно добавлена, иначе возвращает False.

C#[Копировать](# "Копировать")

```
ТекущийОбъект.ДобавитьПодпись("Разраб.", ТекущийПользователь);
```

[Объект.Подписать("(Тип подписи)", [(пользователь)], "(резолюция)")](56A93241.htm)
- Подписывает объект и добавляет резолюцию к объекту. Возвращает True, если объект успешно подписан, иначе возвращает False.

C#[Копировать](# "Копировать")

```
ТекущийОбъект.Подписать("Утв.", "Утверждаю.");
```

[Подпись.ТипПодписи](EA7CC2CB.htm)
- Возвращает наименование типа подписи.

[Подпись.Пользователь](447E6277.htm)
- Возвращает объект пользователя подписи.

[Подпись.ДатаПодписи](BCC8D577.htm)
- Возвращает дату подписи, если объект был подписан, иначе возвращает null.
