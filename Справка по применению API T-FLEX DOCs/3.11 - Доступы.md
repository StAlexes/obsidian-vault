Команды для работы с доступами

`Объект.Доступ.Назначить(пользователь, "доступ", направление доступа)`
- назначает заданный доступ на объект для указанного пользователя или группы пользователей

Направление доступа - выбор применения режима доступа. Возможны следующие варианты применения режима доступа:

- ПоУмолчанию - объект и его дочерние объекты
- Объект - только объект
- ДочерниеОбъекты - только дочерние объекты

C#

```csharp
Объект сборочнаяЕдиница = НайтиОбъект("Документы", "[ID] = '1'"); // Находим объект

if (сборочнаяЕдиница is not null)
    сборочнаяЕдиница.Доступ.Назначить(ТекущийПользователь, "Редакторский", НаправлениеДоступа.ПоУмолчанию); // Назначаем доступ
```csharp
`Объект.Доступ.Назначить("пользователь", "доступ", направление доступа)`
- назначает заданный доступ на объект для указанного пользователя или группы пользователей

C#

```csharp
ТекущийОбъект.Доступ.Назначить("Сотрудники", "Исправление", НаправлениеДоступа.Объект); // Назначаем доступ для группы
```csharp
`Объект.Доступ.НазначитьВсемПользователям("доступ", направление доступа)`
- назначает заданный доступ на объект для всех пользователей

C#

```csharp
ТекущийОбъект.Доступ.НазначитьВсемПользователям("Просмотр", НаправлениеДоступа.Объект); // Назначаем доступ для всех пользователей
```csharp
`Объект.Доступ.Удалить(пользователь, "доступ")`
- удаляет заданный доступ для указанного пользователя или группы пользователей

C#

```csharp
ТекущийОбъект.Доступ.Удалить(ТекущийПользователь, "Редакторский"); // Удаляем доступ
```csharp
`Объект.Доступ.Удалить("пользователь", "доступ")`
- удаляет заданный доступ для указанного пользователя или группы пользователей

C#

```csharp
var сборочнаяЕдиница = НайтиОбъект("Документы", "[ID] = '1'"); // Находим объект

if (сборочнаяЕдиница is not null)
    сборочнаяЕдиница.Доступ.Удалить("Иванов Иван Иванович", "Административный"); // Удаляем доступ
```csharp
`Объект.Доступ.УдалитьВсе()`
- очищает все назначенные для объекта доступы

C#

```csharp
ТекущийОбъект.Доступ.УдалитьВсе();
