Механизм экземпляров обеспечивает возможность вести параллельную копию структуры справочника со сложной иерархией в виде объектов справочника простой иерархии, в котором каждый из объектов связан с объектом исходного справочника и имеет независимый набор параметров и связей

Работа с экземплярами

[ТекущийЭкземплярОбъекта](41A4A226.htm)
- возвращает
экземпляр
, который выбран в окне справочника

[ИсходныйОбъект](453CF700.htm)
- возвращает соответствующий
[объект](95E78982.htm)
исходного справочника

[ИсходноеПодключение](FCF11732.htm)
- возвращает связанное
[подключение](F8466936.htm)
исходного справочника

C#[Копировать](# "Копировать")

```
var текущийЭкземпляр = ТекущийЭкземплярОбъекта; // Получаем текущий экземпляр
var исходныйОбъект = ТекущийЭкземплярОбъекта?.ИсходныйОбъект; // Получаем соответствующий объект исходного справочника
var исходноеПодключение = ТекущийЭкземплярОбъекта?.ИсходноеПодключение; // Получаем связанное подключение исходного справочника
```
