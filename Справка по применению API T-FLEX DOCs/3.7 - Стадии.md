Команды для работы со стадиями.

[`Объект.ИзменитьСтадию("(Стадия)`"[, (Игнорировать схему переходов)])]
- изменяет стадию объекта с возможностью игнорирования схемы переходов. Возвращает True, если стадия успешно изменена, иначе возвращает False.

[`Объект.ИзменитьСтадию("(Стадия)`", "(Комментарий)"[, (Игнорировать схему переходов)])]
- изменяет стадию объекта с возможностью добавления комментария и игнорирования схемы переходов. Возвращает True, если стадия успешно изменена, иначе возвращает False.

C#

```csharp
ТекущийОбъект.ИзменитьСтадию("Хранение", "Комментарий к изменению стадии");
```csharp
[`ИзменитьСтадиюОбъектов((Объекты)`, "(Стадия)"[, (Игнорировать схему переходов)]]
- изменяет стадию объектов с возможностью игнорирования схемы переходов.

[`ИзменитьСтадиюОбъектов((Объекты)`, "(Стадия)", "(Комментарий)"[, (Игнорировать схему переходов)]]
- изменяет стадию объектов с возможностью добавления комментария и игнорирования схемы переходов.

C#

```csharp
Объекты выбранныеОбъекты = ВыбранныеОбъекты;
ИзменитьСтадиюОбъектов(выбранныеОбъекты, "Утверждение", "Комментарий к изменению стадии", true);
```csharp
| Внимание |
| --- |
| Игнорирование схемы переходов доступно администратору.  Если пользователь не является администратором, стадия устанавливается только у объектов, у которых она не задана. |
