### Подключение отладчика к запущенному клиенту DOCs (Attach to Process)

Если макрос обязательно должен работать в окне запущенной программы T-FLEX DOCs (например, брать текущий выделенный пользователем объект на экране):

1. Запусти клиент **T-FLEX DOCs** на компьютере.    
2. В VS Code на панели слева нажми значок **«Запуск и отладка»** (жучок с треугольником, Ctrl + Shift + D).    
3. Нажми **«Создать файл launch.json»** и выбери C#.
4. В файле пропиши
5. 
```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Прикрепиться к T-FLEX DOCs (.NET Framework)",
      "type": "clr",
      "request": "attach",
      "processId": "${command:pickProcess}"
    }
  ]
}
```

1. Нажми зеленую стрелку запуска F5.    
2. Появится список запущенных программ Windows: начни писать TFlexDocs и выбери процесс клиента T-FLEX.    
3. В самом клиенте DOCs запусти свой макрос: как только дойдет до нужной строки, VS Code перехватит управление и подсветит строку в коде.
