### Подключение отладчика к запущенному клиенту DOCs (Attach to Process)

Если макрос обязательно должен работать в окне запущенной программы T-FLEX DOCs (например, брать текущий выделенный пользователем объект на экране):

1. Запусти клиент **T-FLEX DOCs** на компьютере.    
2. В VS Code на панели слева нажми значок **«Запуск и отладка»** (жучок с треугольником, Ctrl + Shift + D).    
3. Нажми **«Создать файл launch.json»** и выбери C#.
4. В файле пропиши код ниже и сохрани   
	```json
	{
  "version": "0.2.0",
  "configurations": [
		    {
		      "name": "Прикрепиться к T-FLEX DOCs (.NET Framework)",
		      "type": "clr",
		      "request": "attach",
		      "processId": "${command:pickProcess}"
		    }
		]
	}
	```
5. Нажми зеленую стрелку запуска F5 на панели **«Запуск и отладка»** .    
6. Появится список запущенных программ Windows: начни писать TFlexDocs и выбери нужный процесс клиента T-FLEX вбивая в поиск tflex.
7. В самом клиенте DOCs открой нужный макрос для редактирования, поставь флаг "Режим отладки" и добавь в код блок 
```c#
	#if DEBUG
	//System.Diagnostics.Debugger.Launch(); //Строго закомментировано или совсем убрать!
	System.Diagnostics.Debugger.Break();
	#endif
```
8. запусти свой макрос: как только он дойдет до нужной строки, VS Code перехватит управление и подсветит строку в коде.
