### Подключение отладчика к запущенному клиенту DOCs (Attach to Process)

Если макрос обязательно должен работать в окне запущенной программы T-FLEX DOCs (например, брать текущий выделенный пользователем объект на экране):

1. Запусти клиент **T-FLEX DOCs** на компьютере.    
2. В VS Code на панели слева нажми значок **«Запуск и отладка»** (жучок с треугольником, Ctrl + Shift + D).    
3. Нажми **«Создать файл launch.json»** и выбери **.NET 5+ and .NET Core / .NET Framework** → выбери конфигурацию **«Attach to Process»** (Подключиться к процессу).    
4. Нажми зеленую стрелку запуска F5.    
5. Появится список запущенных программ Windows: начни писать TFlexDocs и выбери процесс клиента T-FLEX.    
6. В самом клиенте DOCs запусти свой макрос: как только дойдет до нужной строки, VS Code перехватит управление и подсветит строку в коде.
