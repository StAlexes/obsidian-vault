Теперь, когда мы подключили все DLL от T-FLEX DOCs, в VS Code заработал движок **IntelliSense** (умный автокомплит и подсказки по API). В паре с C# он превращает написание кода из мучительного запоминания названий в быстрый конструктор.

Вот 6 главных приемов, которые сэкономят тебе 80% времени при наборе кода макросов.

---

### Прием 1. Принудительный вызов подсказок: `Ctrl` + `Пробел`
Если подсказка исчезла или ты просто хочешь посмотреть, какие методы есть у объекта T-FLEX:
1. Поставь точку после объекта (например: `context.`) или просто начни писать слово.
2. Нажми **`Ctrl` + `Пробел`**.
3. Откроется полный список доступных свойств, методов и событий.
4. **Фильтр на лету:** прямо при открытом списке начни печатать первые буквы метода (например, `getref`) — список сам отфильтрует всё лишнее. Нажми **`Tab`** или **`Enter`**, чтобы вставить.

---

### Прием 2. Рентген типа или метода: `F12` и `Alt` + `F12`
В T-FLEX DOCs огромная объектная модель, и часто непонятно, что именно принимает метод или какие свойства есть у класса `ReferenceObject`.
* **Быстрый просмотр без ухода из файла (`Alt` + `F12`):** наведи курсор на класс (например, `MacroProvider` или `Reference`) и нажми `Alt` + `F12`. Прямо внутри текущей строки откроется мини-окошко с метаданными этого класса из DLL. Закрыть его — клавиша `Esc`.
* **Переход к определению (`F12`):** нажми на любой метод, и VS Code откроет сгенерированный файл с описанием всех полей этого интерфейса.

---

### Прием 3. Подсказка параметров метода: `Ctrl` + `Shift` + `Пробел`
Когда ты вызываешь метод с множеством параметров (например, `catalog.FindObject(...)`):
1. Как только ты открываешь круглую скобку `(`, появляется плашка с описанием первого аргумента.
2. Если плашка случайно закрылась, нажми **`Ctrl` + `Shift` + `Пробел`** — она появится снова.
3. Если у метода есть перегрузки (несколько вариантов вызова), нажимай стрелочки **`Вверх` / `Вниз`** на клавиатуре, чтобы переключаться между вариантами аргументов.

---

### Прием 4. Быстрые исправления («Лампочка»): `Ctrl` + `.` (точка)
Это самая полезная комбинация для C#:
* Забыл добавить `using` в начало файла? Наведи курсор на красное подчеркнутое слово и нажми **`Ctrl` + `.`** → выбери первый пункт, и VS Code сам допишет нужный `using` вверху.
* Нужно переименовать переменную во всем макросе? Нажми **`F2`**, введи новое имя и нажми Enter — переменная переименуется везде, где использовалась.

---

### Прием 5. Сниппеты (шаблоны кода по двум буквам)
Вместо того чтобы писать типовые конструкции руками:
* Напиши **`cw`** и нажми клавишу **`Tab`** дважды → развернется `Console.WriteLine();`.
* Напиши **`for`** или **`foreach`** и нажми **`Tab`** → развернется готовый шаблон цикла.
* Напиши **`prop`** и нажми **`Tab`** → развернется автосвойство `{ get; set; }`.

---

### Прием 6. Быстрое перемещение и дублирование строк
Забудь про бесконечный `Ctrl + C` / `Ctrl + V`:
* **Дублировать строку:** зажми **`Shift` + `Alt` + `Стрелка вниз`** (текущая строка мгновенно скопируется вниз).
* **Переместить строку выше/ниже:** зажми **`Alt` + `Стрелка вверх / вниз`** (строка «поедет» сквозь код на нужную позицию).
* **Быстро закомментировать / раскомментировать блок:** выдели строки и нажми **`Ctrl` + `/`** (слэш).

---

### Пояснение: почему IntelliSense теперь работает так быстро?
Благодаря тому, что в `.csproj` мы прописали `<Private>False</Private>` и указали ссылки на DLL, языковой сервер C# (Roslyn) в фоне прочитал таблицы метаданных сборок DOCs. Он держит в оперативной памяти карту всех типов T-FLEX, поэтому подсказки выскакивают мгновенно без задержек.

---

### Альтернативный путь: всплывающая подсказка мышкой (Hover)
Если горячие клавиши пока не запомнились:
* Просто **наведи курсор мыши на любое слово** в коде и задержи на 1 секунду.
* Появится всплывающая карточка с точным типом данных переменной, возвращаемым значением метода и документацией из библиотеки.
