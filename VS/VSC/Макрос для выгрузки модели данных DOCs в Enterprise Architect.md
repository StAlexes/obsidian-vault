**Макрос для выгрузки модели данных DOCs в Enterprise Architect**  
  
**Введение**  
  
Для решения вопросов ускоренной подготовки документации на систему было  
решено реализовать макрос, способный выгрузить выбранные сущности модели  
данных в файл XML (формата XMI 2.1) для последующего импорта в  
Enterprise Architect и формирования структурных диаграмм.  
  
**Описание**  
  
Макрос представляет собой единый программный код, способный запускаться  
в T-FLEX DOCs 18.1 (более старые версии не проверялись) без  
зависимостей.  
  
Макрос можно запускать напрямую, точка старта - метод Run().  
  
После запуска система предлагает выбрать первый Справочник - источник  
данных.  
  ![[IMG-20261006150742171.webp]]
  
Затем с помощью флагов необходимо выбрать типы объектов Справочника, для  
выгрузки.  
![[IMG-20261006150754863.webp]]  
Следующий шаг - выбор параметров для выгрузки (выводятся все параметры  
справочника, без учета ранее выбранных типов объектов, однако в итоге к  
соответствующему типу будут добавлены только реально подключенные к нему  
параметры).  

![[IMG-20261006150822994.webp]]

Если справочник сложной иерархии - то на следующем шаге будет предложено  
выбрать параметры подключений.  
  
Можно выбирать целые группы параметров - для этого следует поставить  
флаг для целой группы. Также в самом верху можно выбрать все параметры.  
  
На следующем шаге появляется предложение добавить в выгрузку еще один  
справочник.  

![[IMG-20261006150836311.webp]]

У пользователя есть выбор - добавить любой другой независимый  
справочник, или выбрать из списка справочников, имеющих связи на ранее  
выбранные (это удобно, для выгрузки только взаимосвязанных  
справочников).  
  
 ![[IMG-20261006150853757.webp]]\--\>  
![[IMG-20261006150914176.webp]]
  
В случае согласия на добавление справочника - цикл настройки выгрузки  
повторяется.  
  
Когда необходимый набор справочников и типов сформирован - пользователь  
отказывается от добавления очередного справочника и его типов. Система  
формирует перечень связей, существующих для выбранных справочников.  

![[IMG-20261006150929009.webp]]

Выберите интересующие вас связи и нажмите \"Ок\".  
  
Укажите путь для сохранения XML.  
  
Откройте EA, создайте проект? и в нем корневой узел. На закладке Publish  
выберите Import-XMI.  

![[IMG-20261006150949897.webp]]

Импортируйте ранее сформированный файл.  

![[IMG-20261006151003131.webp]]

Подготовьте диаграммы на основе импортированного описания структуры.  
  
В настройках диаграммы, включите отображение элементов Tags и Notes -  
для отображения настроек справочника и комментариев для справочников и  
параметров.  

![[IMG-20261006151020807.webp]]
