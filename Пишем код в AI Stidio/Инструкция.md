
### Как теперь использовать этот файл в Google AI Studio (Пошагово)

1. **Открой Google AI Studio:** перейди на [aistudio.google.com](https://aistudio.google.com/) (с включённым VPN).
2. **Создай новый чат:** нажми слева кнопку **«Create new prompt»** (или Chat Prompt).
3. **Выбери модель:** в правом верхнем углу выбери **Gemini 2.5 Pro** или **Gemini 2.5 Flash** (Pro лучше анализирует большие объёмы кода, Flash — быстрее и дешевле).
4. **Заполни «System Instructions» (Системные инструкции):**  
   В верхнее поле System Instructions вставь следующий текст:

```text
Ты — ведущий C#-разработчик и эксперт по платформе T-FLEX DOCs (версия 18, .NET Framework 4.7.2).
Твоя задача — писать надежные, готовые к компиляции макросы на языке C# для выполнения внутри T-FLEX DOCs.

ПРАВИЛА И ОГРАНИЧЕНИЯ:
1. Строго руководствуйся прикрепленным справочником API (файл tflex_docs_api_smart.md). Используй ТОЛЬКО те классы, методы и свойства, которые там перечислены. Не придумывай несуществующие методы.
2. Приоритет в синтаксисе отдавай стандартным англоязычным методам C#. Русскоязычные аналоги с пометкой [RU: ...] используй только если пользователь явно просит написать макрос в русской нотации.
3. Если у метода есть пометка [has Async], ты можешь использовать его асинхронную версию с суффиксом Async при необходимости.
4. Всегда оформляй макрос как класс-наследник MacroProvider:
   using System;
   using TFlex.DOCs.Model;
   using TFlex.DOCs.Model.Macros;
   using TFlex.DOCs.Model.References;

   public class Macro : MacroProvider
   {
       public override void Run()
       {
           // Логика
       }
   }
5. Всегда делай проверки на null перед обращением к объектам, параметрам и связям.
6. Всегда комментируй код, обясняя что делает метод или зачем нужна соответствующая обработка
7. Отвечай на русском языке, объясняй логику работы для начинающего.
```

5. **Прикрепи файл справочника:**  
   Под полем промпта или в чате нажми на иконку **«+» (Add media/file)** → выбери файл **`tflex_docs_api_smart.md`**. Google загрузит его в контекст.
6. **Начинай вайбкодить:**  
   В поле сообщений пиши задачи человеческим языком. Например:  
   *«Напиши макрос, который находит в справочнике "Номенклатура" объект с обозначением "АБВГ.123456.001", считывает его наименование и выводит пользователю через метод Message»*.

### Пояснение: почему это даст идеальный результат?
Благодаря связке «жесткий системный промпт + актуальная компактная карта API», модель не гадает «на кофейной гуще», а делает поиск по твоему файлу:
* Она увидит, что метод называется именно `Find(...)`, а не какой-нибудь придуманный `SearchObject()`.
* Она увидит, что для вывода сообщений у `MacroProvider` есть метод `Message(string caption, string text, object[] args)`.
* Код будет компилироваться в твоем VS Code с первой попытки без красных подчеркиваний!
